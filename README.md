# Учебная парикмахерская «Фри стайл» (CI/CD проект)

![Deploy static site](https://github.com/Floorsy/FreeStyle/actions/workflows/deploy.yml/badge.svg)

Учебный одностраничный веб-сайт парикмахерской «Фри стайл» (г. Санкт-Петербург) с автоматическим контролем целостности файлов и непрерывным развёртыванием (**CI/CD**) через сервис **GitHub Actions** на хостинге **GitHub Pages**.

* **Публичная ссылка на сайт:** [https://floorsy.github.io/FreeStyle/](https://floorsy.github.io/FreeStyle/)
* **Стек технологий:** HTML5, CSS3, Vanilla JavaScript, GitHub Actions (YAML).
